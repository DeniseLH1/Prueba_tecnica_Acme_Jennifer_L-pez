# Empresa ACME 
 
Aplicacion para la gestión de empleados donde podra crear, eliminar,actualizar, buscar y listar a los empleados que se encuentre en la empresa 

Se utilizo una estructura en capas y se implemento NodeJS
- console: contiene la interfaz para el usuario
- models: contiene el modelo para los empleados 
- services: contiene el servicio para los empleados 

Para correr este proyecto:

node index.js
